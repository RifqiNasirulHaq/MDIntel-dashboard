Cara Deploy ke GitHub Pages (Real-time)

  1. Buka Google Spreadsheet → klik Share → ubah ke "Anyone with the link → Viewer"
  2. Buka tab dashboard di spreadsheet → catat GID dari URL (angka setelah gid=)
  3. Buka file HTML ini → cari baris const SHEET_GID → ganti nilainya sesuai GID tab dashboard
  4. Buat repo baru di GitHub → upload file HTML ini sebagai index.html
  5. Buka Settings → Pages → Branch: main → Save
  6. Dashboard live di https://username.github.io/nama-repo — otomatis update setiap kali dibuka
Cara kerja real-time: Dashboard membaca langsung dari Google Sheets via CSV export publik setiap kali halaman dibuka atau tombol Refresh ditekan. Tidak perlu server, tidak perlu API key, 100% gratis.
